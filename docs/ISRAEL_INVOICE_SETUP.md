# חיבור לחשבוניות ישראל: מדריך הקמה

המדריך מבוסס על שני מסמכים רשמיים של רשות המסים:

- [הנחיות התחברות לשירותי רשות המסים, מהדורה 1.0 (5.2023)](https://secapp.taxes.gov.il/OpenApiUserGuide/OpenApiUserGuide.pdf)
- [מודל חשבוניות ישראל, תיאור ה-API's, מהדורה 2.0 (7.2024)](https://www.gov.il/BlobFolder/generalpage/hor-software-other/he/vat_software-houses-180724.pdf)

## 1. משתמש ברשות המסים

נכנסים לפורטל המפתחים רק עם משתמש קבוע של רשות המסים: מספר זהות, שם משתמש וסיסמה. אי אפשר עם כרטיס חכם. מי שעדיין אין לו משתמש כזה נרשם כאן:
https://secapp.taxes.gov.il/srRishum/main/openPage

## 2. פורטל המפתחים בסביבת הבדיקות

1. נכנסים לכתובת https://openapi-portal.taxes.gov.il/sandbox ומזדהים. בסביבת הבדיקות לא צריך להגיש מסמכים.
2. **Create new organization** ומזינים את שם החברה.
3. **My organization → Apps → Create new app** וממלאים שם, תיאור וכתובת החזרה (OAuth Redirect URI). את כתובת ההחזרה מעתיקים מעמוד **הגדרות עסק** באפליקציה. היא נראית כך:
   `https://<האתר-של-האפליקציה>/api/israel-invoice/oauth/callback`
4. אחרי השמירה מוצגים **Client ID** ו-**Client Secret**. חשוב לשמור את ה-Secret במקום מאובטח, כי אי אפשר לשחזר אותו אחר כך.
5. **Taxes API Products**: בוחרים את המוצר של חשבוניות ישראל, בוחרים את האפליקציה ונרשמים (Subscribe).

## 3. הגדרות השרת ב-Lovable (Secrets)

| שם | ערך |
| --- | --- |
| `ISRAEL_INVOICE_API_ENVIRONMENT` | `sandbox` |
| `ISRAEL_INVOICE_CLIENT_ID` | ה-Client ID מהפורטל |
| `ISRAEL_INVOICE_CLIENT_SECRET` | ה-Client Secret מהפורטל |
| `ISRAEL_INVOICE_SCOPE` | `scope`. זה הערך בדוגמאות הרשמיות. אם בפורטל מופיע ערך אחר לאפליקציה, משתמשים בו |
| `ISRAEL_INVOICE_REDIRECT_URI` | בדיוק הכתובת שנרשמה בפורטל |
| `ISRAEL_INVOICE_OAUTH_STATE_SECRET` | מחרוזת אקראית, ראו בהמשך |
| `ISRAEL_INVOICE_TOKEN_ENCRYPTION_KEY` | מפתח אקראי של 32 בתים ב-base64, ראו בהמשך |
| `SUPABASE_SERVICE_ROLE_KEY` | בדרך כלל Lovable Cloud מספק אותו לבד |
| `ISRAEL_INVOICE_SOFTWARE_REGISTRATION_NUMBER` | לא חובה. מספר רישום התוכנה ברשות המסים (8 ספרות, כמו בקבצי המבנה האחיד). עד שהתוכנה נרשמת, נשלח במקומו מספר העוסק של העסק |

מייצרים את שני הערכים האקראיים במחשב בעזרת הפקודה הזו. מריצים אותה פעמיים, ולכל הגדרה נותנים ערך אחר:

```bash
openssl rand -base64 32
```

**חשוב:** אחרי שעסק התחבר לרשות המסים לא משנים את `ISRAEL_INVOICE_TOKEN_ENCRYPTION_KEY`. אחרת כל העסקים יצטרכו להתחבר מחדש.

בעמוד **הגדרות עסק** יש רשימת בדיקה שמראה אילו הגדרות עדיין חסרות. הרשימה לא מציגה אף ערך סודי.

## 4. חיבור ובדיקה בסביבת הבדיקות

1. פותחים את האפליקציה בכתובת שרשומה כ-Redirect URI, בחלון דפדפן רגיל ולא מתוך חלון התצוגה המקדימה של Lovable. בעמוד **הגדרות עסק** לוחצים על **התחברות לרשות המסים**.
2. בסביבת הבדיקות מזדהים עם אחד ממשתמשי הדמה שמופיעים במדריך הרשמי:
   - משתמש `199999996`, סיסמה `1234QQ`, קוד חד-פעמי `1234QQ`
   - משתמש `199999988`, סיסמה `2175PK`, קוד חד-פעמי `1234qq`
3. בודקים עם חשבונית:
   - בפרטי העסק: סוג העסק הוא עוסק מורשה או חברה, ומספר העוסק תקין. בדוגמאות של המסמך הרשמי מופיע המספר `777777715`.
   - לקוח שמסומן כ"עוסק מורשה" ויש לו מספר עוסק תקין.
   - סכום מעל 5,000 ₪ לפני מע״מ, עם סימון "הלקוח ביקש מספר הקצאה", ואז **שמירה והפקה**.
4. אם רשות המסים מחזירה שגיאת הרשאה (403 או 406), המשתמש שהתחבר לא מורשה לפעול עבור מספר העוסק הזה.

## 5. מעבר לסביבה האמיתית

1. פורטל הייצור נמצא בכתובת https://openapi-portal.taxes.gov.il/shaam/production. כדי להשתמש בו צריך להגיש מסמכי רישום חתומים, ומחכים לאישור שמגיע במייל. המסמכים נמצאים כאן: https://www.gov.il/he/service/connect-to-shaam. תנאי מוקדם הוא רישום לסביבת הבדיקות.
2. בפורטל הייצור יוצרים אפליקציה חדשה, עם כתובת ההחזרה של האתר האמיתי, ומקבלים Client ID ו-Client Secret חדשים. אחר כך נרשמים שוב למוצר של חשבוניות ישראל.
3. ב-Lovable מעדכנים את הפרטים ומשנים את `ISRAEL_INVOICE_API_ENVIRONMENT` ל-`production`.
4. כל עסק מתחבר עם המשתמש שלו ברשות המסים. מי שמתחבר צריך להיות בעל העסק, או מי שהוסמך ברשות המסים לפעול עבור מספר העוסק.
